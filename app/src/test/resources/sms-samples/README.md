# SMS samples for parser tests

Put one Zaad / eDahab SMS per file here, for example `zaad-usd-001.txt` and `edahab-slsh-001.txt`. The parser tests run against every sample.

> ⚠️ **This repository is public.** Before adding a sample, **anonymise it**: replace real names, phone numbers, balances and transaction IDs with fake ones. Keep the exact wording, spacing and punctuation, because that's what the parser has to match.

Example of an anonymised sample (the wording here is made up; use the real SMS wording):

```
[Sender: ZAAD]
Waxaad $25 ka heshay AXMED CALI (0634000001) ...
```

Keep the original, real SMS photos and screenshots off GitHub, for example in a private folder or private Notion page.

# Not-payment SMS

SMS that Codka must **stay silent** for: money you sent, top-ups, currency exchange, and ordinary messages. Every file here must be ignored by the parser.

The Zaad ones are real wording from 222 / 898 (Nov 12, 2026), anonymised: names, numbers, transaction IDs and balances replaced.

Still missing: eDahab "Ayaad u Dirtay" (sent) and "Waxaad ka sarrifatay" (exchange). Add them when you have the full text.
